# ADR-0002: Use Angular for the Web Application

- **Status:** Proposed
- **Date:** 2026-08-05

## Decision

Use Angular 20+ with standalone components, Signals, RxJS, typed reactive forms, and lazy-loaded routes.

## Rationale

- Existing team skill
- Strong structure for enterprise applications
- Built-in routing, forms, DI, testing, and security conventions
- Suitable for storefront and administration experiences

## Consequences

The project must enforce bundle budgets and avoid unnecessary framework complexity.
