# Glossary

| Term | Meaning |
|---|---|
| Available to sell | Quantity currently allowed to be purchased |
| Cart | Temporary collection of intended purchase items |
| Category | Hierarchical product classification |
| Collection | Merchandising grouping that may be campaign-based |
| Customer | Person browsing or purchasing |
| Fulfilment | Picking, packing, and handing an order to delivery |
| Guest checkout | Checkout without a registered password-based account |
| Idempotency | Repeating the same operation does not create duplicate effects |
| Order | Commercial record of items, amounts, customer, delivery, and status |
| Payment | Financial transaction linked to an order or checkout |
| Product | Parent commercial item |
| Promotion | Rule that changes price or provides a benefit |
| SKU | Unique stock keeping identifier for a sellable variant |
| Variant | Sellable product combination such as size and colour |
| Wishlist | Saved products for later consideration |
