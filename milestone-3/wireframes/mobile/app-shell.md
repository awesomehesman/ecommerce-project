# Mobile App Shell Wireframe

```text
+----------------------------------+
| [Menu]      LOGO      [Search][Bag 2] |
+----------------------------------+
|                                  |
|         Routed Page Content      |
|                                  |
+----------------------------------+
| Footer links                     |
+----------------------------------+
```

Requirements:

- Minimum 44x44 touch targets
- Menu focus trap
- Body scroll lock while menu open
- Cart badge announced accessibly
- Sticky header only if usability testing supports it
